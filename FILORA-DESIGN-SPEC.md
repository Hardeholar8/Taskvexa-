# TaskVexa / Filora Design Direction

This document records the approved visual direction for future TaskVexa UI work.

## Core direction
- Premium dark theme only for now. Do not restore or add a white/light theme unless explicitly requested.
- The entire platform should feel like a polished production fintech/productivity mobile app, not a basic HTML site.
- Use the supplied Filora screenshot as the visual quality reference.
- Keep existing TaskVexa functionality, routes, authentication, wallet, tasks, referrals, admin and promoter workflows intact while improving presentation.

## Visual language
- Deep navy/near-black page background.
- Dark elevated cards with subtle borders, depth and soft shadows.
- Strong blue/purple gradients for primary/high-value surfaces.
- Clean modern typography with strong hierarchy.
- Generous but controlled spacing and consistent rounded corners.
- Professional icons; avoid random emoji-heavy presentation where a cleaner icon treatment is possible.
- Inputs, buttons, menus, modals, tables, dashboards and service cards must follow the same dark system.
- Mobile-first responsive polish is important.

## Bottom navigation reference
The Filora-style bottom navigation is an important part of the approved direction:
- Fixed dark navigation bar at the bottom.
- Home, Tasks, centered floating + action, Wallet, More.
- Center + button is elevated above the bar, circular, gradient-filled, and visually integrated into the navigation.
- Navigation spacing should be balanced and uncluttered.
- Active item should have a clear purple accent without becoming oversized.
- Bottom navigation should have subtle blur/depth and safe-area support.

## Dashboard reference
The worker dashboard should use the same premium dark system, with:
- Clear TaskVexa branding.
- Premium hero/balance card.
- Normal-sized stat cards rather than oversized blocks.
- Clean Quick Services cards.
- Consistent section headings and spacing.
- No theme toggle while dark-only mode is active.

## Quality bar
Before considering a UI change complete, visually check the whole page on mobile. Avoid near-duplicate redesigns, inconsistent white surfaces, random spacing, oversized components, or unfinished-looking controls. The target is professional, cohesive and commercial-ready.
